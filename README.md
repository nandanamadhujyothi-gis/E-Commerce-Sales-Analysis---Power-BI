# E-Commerce-Sales-Analysis - Power-BI
Power BI project focused on data transformation, data modeling and e-commerce sales analysis. The project uses e-commerce datasets to organise, transform and prepare sales data for analytical purposes.

Objectives
- Import and transform multiple datasets using Power Query.
- Clean and prepare data for analysis.
- Create calculated and conditional columns.
- Merge datasets using Order ID.
- Identify missing values and duplicate records.
- Sort, filter and group data.
- Establish relationships between tables in Power BI.
  
The project uses the following datasets:
- List of Orders
- Order Details
- Sales Target
